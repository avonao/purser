# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

All contributors and maintainers are expected to follow it in every project space, including issues, pull requests, discussions and any other channel where people represent the project.
